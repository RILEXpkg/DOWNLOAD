روابطك بمكان واحد.

ابحث بالاسم أو كود اللعبة، وقارن الروابط التي أضفتها من PSPKG وViking. واجهة بسيطة، بدون إعلانات مضافة.

الكتالوج يُملأ بالروابط التي تضيفها. لا يوجد ربط تلقائي بالموقعين. تعديلك يُحفظ في هذا المتصفح؛ لمشاركته مع الزوار نزّل نسخة HTML للنشر وارفعها إلى GitHub.

كيف أضيف الروابط وأنشر الموقع؟
  1. اختر «إضافة لعبة» وأدخل الاسم والجهاز ورابط HTTPS من مصدر واحد أو المصدرين.
  2. زر المصدر يفتح الرابط الذي أدخلته كما هو. ضع رابط الملف النهائي إذا كنت تريد الوصول المباشر إليه ولديك حق توزيعه. الروابط المحمية أو المؤقتة تبقى خاضعة لشروط خادم المصدر.
  3. لتنقل بياناتك أو تحفظ نسخة احتياطية استخدم «تصدير JSON». الاستيراد يضيف أو يحدّث السجلات حسب المعرّف.
  4. عندما يجهز الكتالوج، اضغط «تنزيل HTML للنشر» وارفع الملف الناتج باسم index.html. سيظهر الكتالوج المضمّن لكل زائر.
  5. هذه صفحة ثابتة. تعديلات الزوار محلية ولا تغيّر النسخة المنشورة. لا تضع أسرار API أو روابط خاصة أو رموز دخول في كتالوج تنوي نشره.
